# STM32F429IGT6 FSMC NAND Devboards China

Этот репозиторий содержит тестовый проект для отладочных плат на базе микроконтроллера **STM32F429IGT6** (китайского производства), оснащенных внешней памятью **SDRAM** и **NAND Flash**, подключенными через интерфейс **FSMC** (Flexible Static Memory Controller).

Проект представляет собой начальную рабочую версию (Initial working version) и демонстрирует базовые операции с памятью.

## 🚀 Функциональность

На данный момент проект включает в себя тесты для следующих компонентов:

*   **SDRAM**: Инициализация и проверка работы внешней динамической памяти.
*   **NAND Flash**: Базовые операции:
    *   Стирание (Erase)
    *   Запись (Write)
    *   Чтение (Read)

## 🛠️ Аппаратное обеспечение

*   **Микроконтроллер**: STM32F429IGT6 (ARM Cortex-M4).
*   **Память**: Внешние чипы SDRAM и NAND, подключенные к выводам FSMC.
*   **Плата**: Китайская отладочная плата (devboard), вероятно, клон или аналог популярных плат с аналогичной компоновкой.

## 📂 Структура проекта

*   `Core/` — Основной код приложения (исходники, заголовочные файлы, стартап).
*   `Drivers/` — Драйверы от STMicroelectronics (HAL/LL) для STM32F4xx.
*   `EWARM/` — Файлы проекта для среды разработки **IAR Embedded Workbench**.
*   `stm32f429IGT6_testingboards.ioc` — Файл конфигурации **STM32CubeMX**, в котором настроены тактирование, FSMC и GPIO.

## 🔧 Сборка и запуск

1.  Откройте проект в **IAR Embedded Workbench for ARM** (используйте файлы из папки `EWARM`).
2.  При необходимости переконфигурируйте проект с помощью **STM32CubeMX**, открыв файл `.ioc`.
3.  Соберите проект и прошейте микроконтроллер.
4.  Результаты тестов (успех/ошибка) можно наблюдать через отладочный интерфейс (SWD/JTAG).

## 📝 Примечания

*   Проект находится в стадии начальной рабочей версии. Код может требовать адаптации под конкретную ревизию вашей платы.
*   Убедитесь, что тайминги FSMC в файле `.ioc` соответствуют характеристикам установленных на вашей плате чипов памяти.
